# V21 매출 관리와 실시간 대화방

- 관리자 → 매출 관리: 날짜 조회, 일별/주문별 매출, CSV 다운로드.
- 한국시간 주문일 기준이며 최종 결제금액(배송비 포함)에서 해당 주문의 누적 완료 환불액을 차감한다. 결제 발생일이나 PG 정산일별 회계 보고서가 아니다.
- 결제 대기 주문과 진행 중인 환불은 각각 매출·완료 환불액에서 제외한다. 기존 PG 콜백에 취소 금액이 보존되지 않은 주문은 확인 대상으로 표시하며 합계에서 제외하고 CSV 다운로드를 막는다.
- 관리자 → 실시간 대화방 → 전체 대화방 / 1:1 대화방. 전체 대화방은 로그인한 회원과 관리자용 공용 공간, 1:1은 해당 고객과 관리자만 접근하는 상담방이다.
- 고객은 마이페이지 또는 고객게시판의 실시간 대화방 링크로 접속한다. 대화는 서버 DB에 저장되며 이전 대화 조회, SSE 수신, 연결 복구 시 자동 조회를 지원한다.
- 쇼핑몰의 chat.html은 로그인 계정의 관리자 여부와 무관하게 회원 화면을 사용하며 전체 대화방과 본인의 1:1 상담만 조회한다. 고객 선택과 상담 목록은 admin.html에서만 제공한다. 관리자 계정의 쇼핑몰 이용 시에도 계정 권한과 메시지 작성자 역할은 서버가 그대로 검증한다.
- 모든 대화 API는 세션 권한을 검사한다. 쓰기에는 CSRF 검증, 전송 중복 방지 키를 사용하며 열린 스트림도 세션 만료·권한 변경을 재검사한다.
- 기존 데이터에 새 테이블만 추가한다. 빌드 마지막에 v21_operations_patch.py를 적용한다.
- 검증: test_operations.py (로컬 임시 DB), test_operations.cjs (실제 UI 컨트롤러). 운영 주문·대화는 검증을 위해 생성하지 않는다.

이지어드민·이지오토 연동은 사용자 요청으로 보류되었으며 이 배포에 포함하지 않는다.
