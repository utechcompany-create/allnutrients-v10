# V21 구매 리뷰와 사진 첨부

- 배송 완료된 회원의 실제 주문 상품 1건당 리뷰 1개. 관리자 계정·비회원·미결제·미배송·취소 주문은 새 리뷰 작성 불가.
- 별점 1~5점, 후기 5~2,000자. 마이페이지와 상품 상세에서 작성·수정·삭제. 배송 후 반품·환불되어도 이미 구매한 경험의 리뷰는 유지되며 배송 증빙이 있으면 작성 가능.
- 사진 최대 5장, JPG/PNG/WebP, 한 장당 10MB. 실제 이미지 디코딩 후 최대 1,600px JPEG로 변환하고 EXIF를 제거한다. 새 사진은 저장 전 작성자만 접근 가능. 사진과 주문 상품의 소유권을 모두 확인한다.
- 상품 상세에 공개 리뷰, 평균 별점, 구매 인증, 이름 일부 가림, 판매자 답변과 사진 확대 링크 표시. 공개 API에 주문번호·연락처·회원 ID 미포함.
- 관리자 구매 리뷰 메뉴: 전체/미확인/공개/숨김 필터, 답변, 사유가 필요한 숨김 및 재공개. 작성자는 숨김 사유를 확인할 수 있다. 숨긴 리뷰는 공개 목록과 평균에서 제외되고 사진도 비공개로 바뀐다.
- 새 리뷰와 고객 수정은 기존 관리자별 카운터와 알림음에 연결. 화면 하단 확인 또는 답변·관리 작업 시 본 위치까지 확인하며, 이후 들어온 수정은 남는다.
- 수정 버전을 검증해 오래된 화면에서 덮어쓰기를 막고, 주문 상품의 고유 제약과 잠금으로 중복 작성을 방지한다. 작성자가 삭제 후 다시 작성해도 기존 관리자 숨김은 유지된다.
- 추가 테이블: product_reviews, review_photos. 기존 데이터 변경 없이 첫 실행 시 생성.
- 사진은 크기를 줄여 데이터베이스에 저장한다. 서버 재배포 시에도 리뷰 데이터와 함께 유지되며, 접근권한을 확인하는 /api/review-photos/{id}만 제공한다. 목록 조회에서는 사진 원본 데이터를 읽지 않는다.
- 저장하지 않은 사진은 작성자만 볼 수 있다. 사용자가 취소·삭제하면 정리하고, 24시간 지난 임시 사진은 같은 사용자의 다음 업로드에서 정리한다. 임시 사진은 계정당 최대 20장.
- 로컬 테스트: test_reviews.py, test_reviews.cjs. 실제 고객/주문/리뷰 데이터는 테스트에 사용하지 않는다.
