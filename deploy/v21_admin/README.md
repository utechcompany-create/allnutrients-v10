# V21 관리자 개선

- 반품은 관리자의 **입고 완료** 클릭에서 승인된 환불금액으로 환불까지 처리한다. 신규 건의 `receivedAt`과 `completedAt`은 동일하다.
- 카드 등 PG 결제는 취소 완료 응답을 확인한다. 실패 시 입고·재고·완료 상태를 확정하지 않으며 같은 버튼으로 재시도할 수 있다.
- 현금·가상계좌는 실제 송금 후 같은 확인창에서 확인한다. `manualRefundConfirmed: true` 없이 환불 완료로 바꾸지 않는다. 이 기능 자체가 은행 송금을 실행하지는 않는다.
- 0원 환불은 PG 요청 없이 완료한다. 기존 입고/수동 환불 대기 건도 동일 버튼으로 처리할 수 있다.
- 주문 행 잠금 및 결제사 멱등키로 중복 입고·환불을 방지한다. 기존 환불 정책, 회원 내역, 교환 입고→재배송→완료 흐름을 유지한다.
- 관리자 및 반품·교환 관리 화면 왼쪽 메뉴에 미발송 주문, 처리 중 반품, 처리 중 교환, 취소 승인 대기 건수를 표시한다. 메뉴에서 해당 목록으로 이동할 수 있다.
- 건수는 관리자 전용 `/api/admin/work-counts`에서 집계한다. 30초마다, 창 복귀 시, 처리 후 갱신한다. 조회 실패는 `—`로 표시한다.
- 기존 고객 화면 개선과 V21 배송비 규칙 뒤에 `deploy/v21_admin_patch.py`를 적용하며 DB 스키마 변경은 없다.

## 검증

Render와 같은 빌드 후 `deploy/v21_ui/test*`와 `deploy/v21_admin/test*`를 빌드 루트에 복사하고 실행한다.

```sh
python3 test_admin_workflow.py
node test_admin_workflow.cjs
node test_return_request.cjs
node test_mypage_returns.cjs
```

백엔드 검증은 별도 로컬 테스트 DB와 모의 PG 응답을 사용한다. 입고 시 완료, 중복 동시 요청, 실패 시 롤백, 수동 송금 확인, 0원/기존 환불, 교환 처리, 접근 권한, 메뉴 카운터 전환 및 기존 고객 기능을 검증한다.
