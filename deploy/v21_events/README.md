# 관리자 미확인 이벤트와 알림음

- 새 고객 메시지(전체·1:1), 게시글, 상품 문의 및 고객 추가 답변을 원본과 같은 트랜잭션에 기록한다. 관리자 작성 메시지는 새 고객 이벤트로 세지 않는다.
- 첫 배포 때 기존 게시판·상품문의·대화 내역을 한 번 가져온다. 첫 조회는 기존 건수 때문에 소리를 울리지 않는다.
- 확인 상태는 관리자 계정별 서버 저장이다. 대화 하단의 표시된 최신 고객 메시지, 문의 하단을 0.7초 동안 본 경우 또는 확인 버튼/답변 시 해당 위치까지 읽음 처리한다. 숨긴 탭·비활성 화면과 대화 상단을 읽는 중에는 새 메시지를 확인 처리하지 않는다.
- 확인 요청은 화면에서 본 위치만 보낸다. 뒤늦은 요청은 읽음 위치를 되돌리지 않고, 요청 도중 도착한 새 이벤트는 남는다. 관리자 계정이 바뀐 요청은 거부한다.
- 기존 주문·취소·반품·교환 처리 카운터에 전체·1:1 대화, 고객소통 카운터를 더해 5초마다 조회한다. 대화/문의 카운터는 미확인 이벤트 수이고 기존 업무 카운터는 처리 중인 건수다.
- 관리자·반품관리·디자인·네이버관리 화면에 공통 알림을 적용한다. 브라우저가 멈추거나 백그라운드 타이머를 제한하는 동안에는 갱신이 지연될 수 있다.
- 알림음은 첫 사용자 조작으로 활성화되고 끄기/다시 켜기를 제공한다. 증가 때만 재생하며 같은 응답의 여러 메뉴 증가는 한 번만 울린다. Web Locks 지원 브라우저에서 같은 관리자 탭 간 중복 재생을 막는다.
- GET /api/admin/event-counts, POST /api/admin/events/read는 관리자 전용이며 확인 쓰기는 CSRF 검증을 사용한다. 응답은 no-store. 이벤트 테이블에는 원문·연락처를 복사하지 않는다.
- 테스트는 임시 DB 및 DOM/오디오 모형으로 수행한다. 운영 주문·문의·대화를 테스트용으로 생성하지 않는다.
