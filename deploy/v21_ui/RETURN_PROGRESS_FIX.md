# 입고 전 환불 완료 표시 수정

이전 마이페이지는 반품 상태 또는 환불 상태 중 하나만 완료여도 완료로 분류했다. 입고 완료일을 확인하지 않아 서로 다른 상태가 남아 있는 데이터도 완료 금액·완료 필터에 포함될 수 있었다. 반품 신청·조회 화면도 환불 상태 값만으로 완료 금액을 표시했다.

이제 회원 마이페이지와 회원/비회원 반품 조회가 같은 기준을 사용한다. RETURN 신청, 입고 완료일 존재, 반품 상태 REFUNDED 또는 COMPLETED, 환불 상태 COMPLETED 또는 MANUAL_COMPLETED가 모두 충족되어야 완료다. API의 receiptConfirmed/refundCompleted가 false인 경우도 완료로 표시하지 않는다.

입고 전에는 ‘환불 대기 (입고 확인 전)’와 ‘환불 예정 금액’을 표시하며 완료 합계·완료 필터에서 제외한다. 서로 맞지 않는 기존 완료 값이 있으면 고객 화면에 기록 확인 안내를 표시한다. 입고일도 함께 표시한다.

API는 같은 기준의 판정값만 추가한다. 저장된 결제·환불 데이터, 환불 금액, PG 요청은 변경하지 않는다. 기존 입고·환불 완료 작업은 그대로 사용한다. 마이페이지 조회는 no-store를 사용하고, 화면으로 돌아오거나 탭을 다시 활성화하면 갱신한다. 변경 스크립트에는 새 버전 주소를 적용한다.
