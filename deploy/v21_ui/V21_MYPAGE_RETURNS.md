# V21 마이페이지 반품·환불 내역 개선

## 추가한 기능

- 마이페이지에 `반품 / 환불 내역`을 추가했습니다.
- 반품 상품·수량, 신청번호·주문번호, 사유, 상품금액, 반품배송비 차감액, 환불 예정/완료 금액, 신청일·완료일을 표시합니다.
- `전체`, `진행 중`, `반품 완료`로 조회하고 `새로고침`으로 최신 처리 결과를 불러옵니다.
- 상세 사유, 요청사항, 회수 운송장과 판매자 안내를 확인할 수 있습니다.
- 주문별 `반품·교환 내역 확인` 버튼은 전액 환불 후에도 사용할 수 있습니다.
- 마이페이지의 반품 차감 안내를 V21 정책에 맞췄습니다.

## 적용 파일

- `static/mypage.html`
- `static/assets/mypage-returns.js`
- `static/assets/mypage-returns.css`
- `static/return-request.html`
- `static/assets/return-request.js`

기존 회원 인증과 `/api/returns/my`를 그대로 사용합니다. 데이터베이스 변경이나 환불 금액 계산 변경은 없습니다. 기존 완료 내역도 표시됩니다.

이 압축파일은 수정 소스입니다. 운영 서버 배포는 별도입니다. GitHub의 압축 소스 해제·패치 방식으로 배포할 경우, 위 5개 파일은 기존 모든 패치가 적용된 **후** 최종 결과에 포함되어야 합니다. 기존 배포 단계에서 수정 화면을 다시 덮어쓰지 않도록 주의하세요.

## 반품·교환 신청 화면 복구

- 주문번호 없이 직접 열어도 회원 주문을 선택하거나 비회원 주문정보를 입력할 수 있습니다.
- 반품/환불·교환 유형, 사유, 상품·수량, 첨부사진, 신청 등록 화면을 항상 표시합니다.
- 미결제, 배송 전, 전체 반품 완료 등 신청 불가 상태는 폼을 비활성화하고 이유를 표시합니다.
- 송장만 등록된 주문도 서버와 같은 기준으로 신청할 수 있습니다.
- 신청·완료 내역을 브라우저의 `history` 객체와 충돌하지 않는 화면 요소에 표시합니다.
- 이미 신청한 수량을 제외한 잔여 수량을 표시하고, 완료된 교환상품의 재신청은 허용합니다.
- 회원 로그인 상태에서도 비회원 주문 링크는 비회원 확인 절차로 처리합니다.

## 검증

`python test_mypage_returns.py` — V21 차감 정책, 부분·전체 반품 완료, 현금·카드 환불, 회원별 내역 접근 및 자산 응답 확인. 카드 환불은 외부 결제 호출 없이 모의 응답으로 검증합니다.

`node test_mypage_returns.cjs` — 표시 상태, 완료 합계, 필터, 재조회, 실패/빈 내역, 입력 문자열 이스케이프 및 전액 환불 주문의 조회 버튼 확인.

`node test_return_request.cjs` — 외부 접속 없이 실제 신청 화면 코드를 실행해 직접 진입, 주문 선택, 회원·비회원 반품/교환 신청, 신청 수량, 오류 후 재시도 및 완료 내역 표시를 검증합니다.

`python test_return_request.py` — 기존 반품 정책·완료 내역 테스트와 함께 송장만 있는 주문의 반품·교환 접수 및 중복 수량 거절을 검증합니다. 테스트 실행에는 `httpx`가 추가로 필요합니다.
