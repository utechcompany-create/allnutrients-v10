# V21 모바일 화면 및 회원 배송지

- 기존 URL의 고객용 11개 페이지에만 모바일 CSS/JS를 적용한다. 관리자 화면과 서버의 가격·환불 정책은 그대로 사용한다.
- 760px 이하에서 하단 탐색, 전체메뉴, 2열 상품, 하단 구매/결제 버튼, 주문 내역 카드, 확대 없는 입력 글꼴과 기기 안전영역을 적용한다.
- 장바구니 바로가기 `index.html?openCart=1`을 처리한다. 장바구니 수량, 결제 금액은 기존 값을 표시하며 계산을 복제하지 않는다.
- 회원 주문서에서 저장 배송지를 선택·삭제할 수 있다. 저장 체크 시 주문 생성과 같은 DB 트랜잭션에서 배송정보를 저장하며 주문 실패 시 함께 롤백한다. 비회원은 저장하지 않는다.
- 배송지 정보: 수령인, 연락처, 우편번호, 주소, 상세주소, 배송메모. 회원당 최대 20개이며 같은 정보는 재사용한다. 주소록 삭제는 과거 주문에 영향을 주지 않는다.
- `/api/shipping-addresses` GET/POST, `/api/shipping-addresses/{id}` DELETE는 로그인한 소유자만 허용한다. 쓰기는 CSRF 검사, 조회는 no-store. 관리자도 다른 회원 주소록을 조회·삭제할 수 없다.
- `shipping_addresses` 테이블은 기존 create_all 절차로 추가된다. 주소 데이터는 브라우저 저장소에 보관하지 않는다.
- 최종 빌드에서 v21_mobile_patch.py가 기존 모든 V21 패치 이후에 실행된다.
