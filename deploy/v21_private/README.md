# 비밀 문의와 게시글

- 상품 상세 문의 및 고객게시판 작성폼에서 `비밀글로 작성`을 선택한다. 선택하지 않은 글과 기존 글은 공개 상태를 유지한다.
- 비밀글의 제목, 작성자, 본문, 추가 문의 및 관리자 답변은 작성자와 활성 관리자에게만 반환한다. 다른 회원 및 비회원의 응답에는 안내 문구와 빈 본문/답변 배열만 포함된다.
- 비밀글의 추가 문의는 작성자·관리자에게만 허용하며, 관리자 고객소통 화면에는 비밀글 표시와 전체 대화가 보인다.
- 계정별 목록 응답은 `Cache-Control: private, no-store` 및 `Vary: Cookie`를 사용한다. 브라우저 이력 복귀 및 창 복귀 시 재조회하고 오래된 응답이 새 목록을 덮어쓰지 않도록 한다.
- 새 `communication_privacy` 테이블을 앱 시작 시 기존 `Base.metadata.create_all`로 생성한다. 문의/게시판 기존 테이블이나 데이터를 변경하지 않는다. 글과 비공개 설정은 같은 트랜잭션에 저장한다.
- 비밀글을 생성한 뒤에는 비밀글 권한 검사를 포함하지 않은 이전 앱 버전으로 되돌리지 않는다.

## 검증

배포 빌드 후 이 폴더의 테스트 파일을 빌드 루트에 복사한다.

```sh
python3 test_private_inquiries.py
node test_private_inquiries.cjs
```

테스트는 임시 로컬 DB에서 기존 공개 데이터 보존, 새 테이블 생성, 회원별 접근 제어, 비밀 답변 차단, 추가 문의 권한, 로그아웃, 캐시, 저장 오류 시 원자성 및 렌더링/체크박스 전송을 검증한다.

같이 반영한 `deploy/v21_admin/static/assets/admin-labels.js`는 관리자 주문·배송의 결제상태, 주문상태, 배송상태, 결제수단과 취소 신청 상태를 한글로 표시한다. 선택 목록의 `value`는 기존 코드로 유지한다. `test_admin_labels.cjs`에서 한글 표기 및 상태 변경 요청 값을 검증한다.
